# Megan — Ethereum Meme-Coin Research

مخزن توسعه ربات پژوهش و کشف زودهنگام میم‌کوین‌ها؛ زنجیره فعال فعلی فقط Ethereum Mainnet است.

## وضعیت فعلی
- [کشف قراردادها و استخرها](src/megan_watcher.py): اسکن بلوک، CREATE مستقیم، CREATE/CREATE2 داخلی از طریق trace و رویدادهای factoryهای V2/V3 که پیکربندی شده باشند.
- [اتصال منابع عمومی بازار](src/public_sources.py): GeckoTerminal، DEX Screener و Honeypot.is.
- [موتور ارزیابی ریسک](src/risk_engine.py): امتیاز ریسک و فرصت، موانع سخت، هشدارها و داده‌های نامعلوم.
- [تحلیل وضعیت LP](src/lp_analysis.py): تفکیک توکن‌های LP قفل‌شده، آزاد، سوزانده‌شده و نگهداری‌شده در قراردادهای ناشناخته؛ فقط با snapshot کامل و lock record تأییدشده. این ماژول فعلاً تحلیل‌گر داده ورودی است و هنوز به RPC/locker registry متصل نشده است.
- [تحلیل هولدرها](src/holder_analysis.py): محاسبه تمرکز ۱۰ هولدر بر اساس snapshot کامل و قابل تطبیق با totalSupply؛ تفکیک burn، جفت‌ارز LP و locker تأییدشده از عرضه در گردش. این ماژول هنوز به گردآوری زنده Transfer logs و balanceOf متصل نشده است.
- [اسکنر پژوهش](src/megan_research.py): کشف استخرهای تازه Ethereum، دریافت داده‌های بازار و ذخیره گزارش در SQLite.
- [آزمون‌ها](tests/) و [GitHub Actions](.github/workflows/python-tests.yml).

## نصب و اجرا
Python 3.11 یا بالاتر:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev,telegram]"
cp .env.example .env
python -m pytest -q
```

### کشف قرارداد و استخر در زنجیره
`ETHEREUM_RPC_URL` را در `.env` تنظیم کنید. برای دیدن CREATE2 داخلی، RPC باید trace API داشته باشد. به‌صورت پیش‌فرض `TRACE_REQUIRED=true` است؛ اگر trace در دسترس نباشد، اسکنر جلو نمی‌رود تا بلوک‌های ناقص را بی‌صدا رد نکند. فقط در صورت پذیرش صریح پوشش ناقص، آن را `false` کنید:

```bash
megan-run
```

این دستور پایش قراردادهای تازه، داده‌های بازار و شبکه‌های اجتماعی را هم‌زمان اجرا می‌کند. اگر فقط کشف قرارداد لازم دارید، از `megan-watch` استفاده کنید.

### snapshot هولدرهای ERC-20 از Ethereum

برای استخراج آدرس‌های شرکت‌کننده در رویدادهای Transfer از بلاک استقرار تا بلاک snapshot، سپس خواندن balanceOf و تطبیق با totalSupply:

```bash
megan-holders --token 0xTOKEN_ADDRESS --deployment-block 19000000 --chunk-size 2000
```

RPC باید آرشیو لاگ‌های بازه موردنیاز را ارائه کند؛ اجرای تست‌ها با mock RPC است و جای اجرای زنده روی شبکه را نمی‌گیرد. خروجی فقط زمانی complete می‌شود که بلاک snapshot در طول خواندن reorg نشده باشد و مجموع balanceOfها دقیقاً با totalSupply برابر شود. این دستور فقط خواندنی است. آدرس‌های LP pair و locker تا زمان ارائه شواهد مستقل، به‌صورت خودکار مستثنا نمی‌شوند. برای توکن‌های rebase، reflection، یا توکن‌های غیر استاندارد، عدم تطبیق به UNKNOWN منجر می‌شود.

### بررسی LP توکن‌های Uniswap V2

بدون registry، موجودی قراردادها UNKNOWN می‌ماند. برای افزودن adapter باید ABI واقعی پروتکل را مستقل بررسی کنید و آدرس قرارداد، bytecode hash، selectorهای `lockCount(address)` و `lockInfo(address,uint256)` با خروجی دقیق `(address,uint256,uint256)` را در فایل registry ثبت کنید. نمونه `config/v2-lockers.example.json` عمداً فاقد locker تأییدشده است. مقدار `coverage_complete` را فقط وقتی `true` کنید که پوشش فهرست lockerهای موردنظر را واقعاً بررسی کرده‌اید.

نمونه اجرا:

```bash
megan-lp --pair 0xPAIR_ADDRESS --created-block 19000000 --lockers-file config/my-v2-lockers.json
```


برای خواندن توکن LP جفت‌ارز V2 از بلاک ایجاد جفت تا بلاک snapshot:

```bash
megan-lp --pair 0xPAIR_ADDRESS --created-block 19000000
```

این دستور موجودی مستقیم EOAها، آدرس‌های burn و موجودی نگهداری‌شده در قراردادها را جدا می‌کند. موجودی قراردادها تا زمان تأیید locker و مقدار/زمان قفل، UNKNOWN می‌ماند. این ابزار فقط برای LP توکن‌های Uniswap V2 است.

### بررسی سابقه Deployer ثبت‌شده در دیتابیس محلی

```bash
megan-deployer --creator 0xCREATOR_ADDRESS --db data/megan.sqlite3
```

این گزارش فقط قراردادهایی را نشان می‌دهد که اسکنر قبلاً در دیتابیس ثبت کرده است؛ اگر بازه اسکن کامل نباشد، سابقه ناقص است. تعداد Rugها و ارتباط کیف‌پول‌های تأمین‌کننده مالی از این داده به‌تنهایی قابل اثبات نیست و UNKNOWN باقی می‌ماند.

### پیدا کردن تلگرام و X

برای بررسی لینک‌های اجتماعی قراردادهای تازه ثبت‌شده:

~~~bash
megan-socials --once
megan-run  # اجرای هم‌زمان پایش لانچ، بازار و شبکه‌های اجتماعی

# یا فقط پایش شبکه‌های اجتماعی:
megan-socials --interval 15
~~~

DEX Screener به‌صورت رایگان فهرست پروفایل‌های تازه و لینک‌های اجتماعی را می‌دهد. برای اطلاعات اجتماعی DEXTools، متغیر DEXTOOLS_API_KEY را تنظیم کنید. برای جست‌وجوی پست‌هایی که آدرس قرارداد را در X دارند، X_BEARER_TOKEN لازم است. بدون کلید X، لینک جست‌وجوی مستقیم X در گزارش می‌آید. برای جست‌وجوی گروه‌ها و کانال‌های تلگرام با آدرس قرارداد، قابلیت اختیاری MTProto را فعال کن: `pip install -e ".[telegram]"`، سپس TELEGRAM_API_ID و TELEGRAM_API_HASH را از my.telegram.org در فایل محلی .env بگذار و یک‌بار `megan-telegram-login` را اجرا کن. ورود و کد تأیید فقط روی دستگاه خودت انجام می‌شود و فایل session را نباید در GitHub بگذاری. بعد از آن، megan-run گروه‌ها و کانال‌هایی را که پیام شامل آدرس قرارداد دارند جست‌وجو می‌کند.

در گروهی که با آدرس دقیق قرارداد پیدا شود، مگان تاریخ ساخت قابل‌مشاهده گروه، رویدادهای ساخت گروه در تاریخچه قابل‌دسترسی، پیام‌های service مربوط به اضافه‌شدن bot و فهرست botهای قابل‌مشاهده تا سقف ۱۰۰ عضو را هم ثبت می‌کند. محدودیت تلگرام: جست‌وجو با MTProto و نشست کاربری خودت انجام می‌شود، نه Bot API. فقط گروه‌هایی پیدا می‌شوند که تلگرام در جست‌وجوی سراسری برای آن حساب نمایش می‌دهد؛ تاریخچه و فهرست اعضا هم ممکن است به‌دلیل دسترسی/محدودیت تلگرام ناقص باشد. بنابراین نبود bot یا رویداد ساخت، به معنی نبود آن نیست. لینک‌ها و پیام‌ها مدرک حضور آدرس قراردادند، نه اثبات رسمی‌بودن یا معتبر بودن گروه.

### اسکن منابع عمومی بازار
بدون کلید خصوصی و بدون اتصال کیف‌پول:

```bash
megan-research --once
megan-research --interval 30
```

فقط استخرهای Ethereum Mainnet با نقدینگی مشاهده‌شده **بیشتر از ۱۰۰ دلار** از فیلتر اعلام عبور می‌کنند؛ مقدار ۱۰۰ دلار یا کمتر رد می‌شود. فیلتر به LP lock/burn وابسته نیست. خروجی هر نامزد واجد شرایط به‌صورت JSON چاپ و در `data/megan.sqlite3` ذخیره می‌شود.

## اصل امنیتی مهم
قفل‌نبودن نقدینگی به‌تنهایی «فرصت خرید» نیست؛ یعنی امکان خروج نقدینگی وجود دارد. موتور آن را ریسک محسوب می‌کند. نبود داده هرگز به‌عنوان امن‌بودن تفسیر نمی‌شود. شکست شبیه‌سازی فروش یا تشخیص Honeypot مانع سخت است. امتیازها heuristic هستند و جای بررسی مستقل را نمی‌گیرند.

## محدودیت نسخه حاضر
این نسخه یک MVP پژوهشی است، نه شکارچی خودکار سود و نه سامانه آماده سرمایه‌گذاری. کشف استخرهای تازه را از GeckoTerminal می‌گیرد؛ پوشش همه factoryهای اختصاصی و قراردادهای فاقد استخر تضمین نشده است. DEX Screener اطلاعات جفت‌ارز و فعالیت می‌دهد، اما تعداد خرید/فروش آن معادل تعداد کیف‌پول‌های یکتا نیست. بررسی قفل LP، snapshot کامل هولدرها، تحلیل bytecode/proxy و اختیارات مدیریتی، سابقه deployer، تشخیص خوشه کیف‌پول‌ها، رتبه‌بندی چندمرحله‌ای هنوز نیازمند تکمیل و اعتبارسنجی است. لینک‌های اجتماعی نیز فقط وقتی معتبرند که منبع و تطبیق دقیق آدرس ثبت شده باشد.

«کل اینترنت» یا «کل تلگرام» قابل اسکن تضمین‌شده نیست. تلگرام فقط از روی لینک‌های ثبت‌شده در DEXTools و DEX Screener بررسی می‌شود؛ جست‌وجوی سراسری همه گروه‌ها با آدرس قرارداد در Bot API تلگرام وجود ندارد.

## امنیت عملیاتی
- هیچ private key یا seed phrase وارد نکنید.
- هیچ خرید یا فروش خودکاری وجود ندارد.
- پیش از هر استفاده واقعی، API schemaها، خطاهای منبع داده، نرخ درخواست، reorgها و نتایج false positive/negative باید با داده زنده آزمایش شوند.
- `.env` را هرگز commit نکنید.


## محدوده پروژه
مگان فقط برای میم‌کوین‌ها و شت‌کوین‌هاست. هیچ بخش NFT یا Uniswap V3 position-NFT در این پروژه وجود ندارد.


فایل نشست تلگرام در data/ ذخیره می‌شود و باید خصوصی بماند؛ آن را به GitHub یا هیچ‌کس دیگری ارسال نکن.
