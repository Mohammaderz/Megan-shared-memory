# Megan — Ethereum Meme-Coin Research

مگان فقط برای **Ethereum Mainnet (chain_id=1)** طراحی شده است.

## اجزای فعلی
- `megan-watch`: کشف قراردادهای CREATE و CREATE2 با RPC و رویداد factoryهای تنظیم‌شده.
- `megan-sources`: دریافت هشدارهای قرارداد از RSS/Atom و کانال‌های عمومی تلگرامِ پیکربندی‌شده؛ استخراج آدرس‌های ۲۰ بایتی اتریوم و حذف پیام‌های تکراری.
- `megan-research`: دریافت داده‌های بازار و گزارش ریسک از منابع عمومی.
- `risk_engine`: امتیازدهی توضیح‌پذیر با تفکیک داده نامعلوم از داده امن.

## نصب
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
pytest -q
```
برای اتصال تلگرام:
```bash
pip install -e ".[telegram]"
```
مقادیر `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` را فقط در فایل محلی `.env` قرار دهید و یک session مجاز Telethon بسازید. Megan از Bot API برای خواندن دلخواه همه کانال‌ها استفاده نمی‌کند؛ دسترسی به کانال‌های خصوصی یا کانال‌هایی که حساب مجاز عضو آن نیست تضمین‌شده نیست. شرایط استفاده تلگرام و مجوز دسترسی باید رعایت شود.

## اجرای دریافت هشدار
در `.env`، آدرس RSS/Atomها را در `RSS_ALERT_FEEDS` و نام کانال‌های عمومی را در `TELEGRAM_CHANNELS` با کاما جدا کنید:
```bash
megan-sources --once
megan-sources --interval 3
```
هر پیام تازه‌ای که آدرس قرارداد اتریوم داشته باشد، همان چرخه به `analyze_token_address` تحویل داده می‌شود؛ حتی اگر هنوز هیچ استخر DEX برای آن ساخته نشده باشد. پیام و آدرس‌ها در SQLite ثبت و پیام‌های تکراری حذف می‌شوند. ابتدا آدرس قرارداد به Honeypot.is و DEX Screener برای بررسی اولیه ارسال می‌شود؛ نبود جفت معاملاتی مانع ثبت و تحلیل اولیه نیست.

**محدودیت مهم فعلی:** این نسخه لایه دریافت هشدار و استخراج آدرس را اضافه می‌کند؛ هنوز اتصال end-to-end هشدار به تحلیل کامل قرارداد/شبیه‌سازی خریدوفروش/موتور امتیازدهی به‌صورت خودکار تکمیل و تست زنده نشده است. این مرحله بعدی است. زمان دریافت واقعی وابسته به سرعت انتشار منبع و polling آن است؛ تضمین «در همان میلی‌ثانیه دیپلوی» ممکن نیست. برای کشف زنجیره‌ای، RPC WebSocket/mempool و trace مناسب نیز لازم است.

هیچ کلید خصوصی یا seed phrase وارد نکنید. این برنامه در وضعیت فعلی فقط مشاهده و پژوهش می‌کند و خرید/فروش انجام نمی‌دهد.
