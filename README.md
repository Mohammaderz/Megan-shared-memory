# Megan — Ethereum Meme-Coin Research

مگان فقط برای **Ethereum Mainnet (chain_id=1)** طراحی شده است.

## اجزای فعلی
- `megan-watch`: کشف قراردادهای CREATE و CREATE2 با RPC و رویداد factoryهای تنظیم‌شده.
- `megan-sources`: دریافت هشدارهای قرارداد از RSS/Atom و کانال‌های عمومی تلگرامِ پیکربندی‌شده؛ استخراج آدرس‌های ۲۰ بایتی اتریوم و حذف پیام‌های تکراری.
- `megan-research`: دریافت داده‌های بازار و گزارش ریسک از منابع عمومی.
- `risk_engine`: امتیازدهی توضیح‌پذیر با تفکیک داده نامعلوم از داده امن.

## نصب
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
pytest -q
```
برای اتصال تلگرام:
```bash
pip install -e ".[telegram]"
```
مقادیر `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` را فقط در فایل محلی `.env` قرار دهید و یک session مجاز Telethon بسازید. Megan از Bot API برای خواندن دلخواه همه کانال‌ها استفاده نمی‌کند؛ دسترسی به کانال‌های خصوصی یا کانال‌هایی که حساب مجاز عضو آن نیست تضمین‌شده نیست. شرایط استفاده تلگرام و مجوز دسترسی باید رعایت شود.

## اجرای دریافت هشدار
در `.env`، آدرس RSS/Atomها را در `RSS_ALERT_FEEDS` و نام کانال‌های عمومی را در `TELEGRAM_CHANNELS` با کاما جدا کنید:
```bash
megan-sources --once
megan-sources --interval 3
```
پیام‌های تازه حاوی آدرس قرارداد در SQLite ثبت و تکرارزدایی می‌شوند. آدرس تا زمان مشاهده یک استخر روی Ethereum Mainnet با نقدینگی **بیشتر از ۱۰۰ دلار** در صف انتظار می‌ماند؛ فقط پس از عبور از این آستانه به‌عنوان توکن واجد شرایط اعلام و تحلیل ریسک می‌شود. مقدار دقیق ۱۰۰ دلار یا کمتر، و توکن بدون استخر، اعلام نمی‌شود. وضعیت قفل/باز بودن LP یا سوزانده‌شدن آن شرط اعلام نیست و صرفاً در صورت وجود داده به‌عنوان شاهد ریسک ثبت می‌شود.

**محدودیت مهم فعلی:** دریافت آدرس از RSS و کانال‌های عمومی تلگرام پیاده شده است، اما رصد سراسری تلگرام برای کشف خودکار هر گروه/کانال تازه‌ساخته‌شده ممکن نیست. برای تشخیص رویدادهای ساخت گروه و اضافه‌شدن ربات باید حساب مجاز تلگرام به گروه‌های هدف دسترسی داشته باشد و گروه‌ها/لینک‌هایشان به مانیتور معرفی شوند؛ این بخش هنوز پیاده‌سازی و تست زنده نشده است. اتصال end-to-end به تحلیل کامل بایت‌کد قرارداد، مجوزهای مالک، تاریخچه سازنده و شبیه‌سازی مستقل خریدوفروش نیز هنوز کامل نیست. زمان دریافت واقعی وابسته به سرعت انتشار منبع و polling آن است؛ تضمین «در همان میلی‌ثانیه دیپلوی» ممکن نیست. برای کشف زنجیره‌ای، RPC WebSocket/mempool و trace مناسب نیز لازم است.

هیچ کلید خصوصی یا seed phrase وارد نکنید. این برنامه در وضعیت فعلی فقط مشاهده و پژوهش می‌کند و خرید/فروش انجام نمی‌دهد.
