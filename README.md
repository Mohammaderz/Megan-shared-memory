## قابلیت‌های MVP
- اتصال فقط‌خواندنی به Ethereum Mainnet از طریق JSON-RPC.
- پیمایش بلوک‌ها با فاصله تأیید قابل تنظیم.
- شناسایی قراردادهای تازه‌مستقرشده و غربال اولیه قراردادهای ERC-20-like.
- پایش رویداد ایجاد استخر در factoryهای V2-style و V3-style که آدرسشان در تنظیمات وارد شده باشد.
- ذخیره توکن‌ها، استخرها، رویدادها و cursor پردازش در SQLite.
- ادامه پردازش از آخرین بلوک ذخیره‌شده پس از راه‌اندازی مجدد.
- بدون کلید خصوصی، امضای تراکنش یا معامله خودکار.

## نصب و اجرا
Python 3.11 یا بالاتر لازم است.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

مقدار `ETHEREUM_RPC_URL` را در `.env` وارد کنید. آدرس factoryها اختیاری‌اند؛ فقط آدرس‌های تأییدشده و متعلق به Ethereum Mainnet را تنظیم کنید.

```bash
megan-watch
```

برای اسکن بلوک‌های واجد تأیید و خروج:

```bash
megan-watch --once
```

برای اسکن تاریخی از بلوک مشخص، `START_BLOCK` را تنظیم کنید. اگر خالی باشد، برنامه از نوک واجد تأیید در زمان شروع آغاز می‌کند.

## محدودیت‌های مهم
این نسخه فقط کشف اولیه انجام می‌دهد و هنوز موتور امتیازدهی، تحلیل عمیق bytecode، تشخیص honeypot، گراف کیف‌پول، تحلیل کامل هولدرها، ردیابی Bonding Curve، قیمت‌گذاری و داشبورد ندارد. تشخیص ERC-20 heuristic است. فقط factoryهای پیکربندی‌شده پوشش داده می‌شوند. تعداد تأیید، احتمال reorg را کاهش می‌دهد اما نسخه فعلی rollback خودکار زنجیره‌ای ندارد. این برنامه هنوز پیش از آزمون و بازبینی برای استفاده عملیاتی آماده نیست.

**امنیت:** RPC URL ممکن است کلید API داشته باشد؛ `.env` را commit نکنید. کلید خصوصی کیف‌پول وارد برنامه نکنید.
